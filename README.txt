【Unitを追加するとき（b3 の Unit 1 を足す例）】
  1. data/b3_unit1.js を data フォルダに追加
  2. index.html の「<script src="data/b2_unit10.js"></script>」の下に
       <script src="data/b3_unit1.js"></script>
     を1行追加
  3. sw.js の DATA に 'data/b3_unit1.js' を追加し、CACHE のバージョン（v2 など）を1つ上げる
  ※ b1（中学修了～高校基礎レベル：Unit 1〜8）と b2（大学合格必須レベル：Unit 1〜10）はすべて入っています。
  ※ b3（難関大学突破レベル）は Unit 12 まで全て入っています（全1167語）。
     ※ b1/b2 と重複する35語は b3 から除いてあるため、各Unitは100語ぴったりではありません。

【オフラインについて】
  初回は一度オンラインで開くと、全ファイルが端末に保存されます。以降は完全オフラインで起動します。
  発音（🔊）は端末の英語音声を使うため、端末に英語音声データが入っていない場合はオフラインで鳴らないことがあります。

【学習記録について】
  「覚えた」「また後で」・ゲームの最短記録・インベーダーの記録は、単語帳ごとに別々に保存されます。
  データ管理の書き出し／読み込みは、7つの単語帳の記録をまとめて扱います。

【単語データの形式（data/bX_unitN.js）】
  n:番号  p:主な品詞(n/v/a/adv)  e:英単語  i:発音記号（[ ]なし）
  s:[[品詞,意味],…]  x:[[例文,和訳],[例文,和訳]]（例文中の [[ ]] が答えの語、和訳中の【 】が訳語）
  dv:派生語  sn:類義語  an:反意語  tp:用法  （大学合格必須レベル以降は et:語源  rl:関連語 も使う）

【単語検索について】
  ホーム画面の検索ボックスに英語または日本語を入れて「検索」ボタン（またはEnter）を押すと、全冊をまとめて検索します（入力中は検索しないので軽く動きます）。
  ・対象は見出し語（英語）と意味（日本語）。部分一致で、大文字小文字・ひらがな/カタカナ・「〜」の違いは区別しません。
  ・並び順は 完全一致 → 先頭一致 → 部分一致 の順。最大100件まで表示します。
  ・各結果の上に「第◯冊 単語帳名 ／ Unit ◯ ／ No.◯」が出ます。その帯をタップすると、該当Unitの単語一覧が開き、その単語が黄色く強調されます。

【学習ログ・連続日数・カレンダー（2026-10 更新・第1段階）】
  ・カードを裏返した語を「触れた語」として数える（1日1語1回まで／ゲームで正解した語・クイズの正解語も数える）。日付の切り替えは朝4時。
  ・5語以上触れた日を「学習した日」とする（MIN_DAY）。累計日数は減らない。連続日数は、前回のお休みから7日以上あいていれば1日だけお休みしても途切れない。
  ・1日の目標は 10/20/30/50/100語（初期20語）。トップに今日のリング、🔥連続・累計・最長連続、「今日の10語」ボタン。
  ・「今日の10語」：復習（また後で）最大3語＋まだ触れていない新しい語。足りなければ最も長く触れていない語で補充。
  ・カレンダー画面（トップのリングまたはリンクから）で月ごとの学習数を確認。
  ・保存先は進捗データ(store)内の days / seen / today / dailyGoal / lastBook / lastDir（書き出しにも含まれる）。sw.js の CACHE は v28。

【範囲指定の目標・自動逆算（2026-10 更新・第2段階）】
  ・目標＝「単語帳の範囲（Unit○ No.○ 〜 Unit○ No.○）× 周回数（1/2/3/5周）を、期限までに終える」。最大3つ。トップ画面の「🎯 目標」から作成・編集・削除。
  ・周回は「別の日に1回見る」を1回と数える（1語につき周回数まで加算）。範囲外の語は数えない。
  ・ノルマは毎日、残り回数 ÷ 残り学習日数（週の学習日数5/6/7日で計算）から再計算（遅れた分は自動で上乗せ）。1週・1ヶ月のペースも同じ式で表示。
  ・進捗バーの黒線は「今日のノルマを終えたときの計画位置」。先行／遅れは今日の学習を始める前の時点で比較。
  ・トップのリングは、期限が最も近い目標の「今日のノルマ」を表示。「▶ 目標の今日のノルマを始める」で、見た回数の少ない語から出題。
  ・カレンダーに目標の期限（🎯）を表示。目標データは store.goals（書き出しにも含まれる）。sw.js の CACHE は v29。

【修正・第3段階（2026-10 更新）】
  ・目標から再開すると前回の続きから表示（同じ日の未完了セッション。ボタンは「続きから」）。新しくデッキを作るときは、今日すでに出した語・触れた語を避ける。
  ・「覚えた」（その方向）の語は目標の出題から除外し、周回済みとして数える。「今日の10語」でも覚えた語は出さない。
  ・周回の判定：最後までやりきるまで次の周にならない（同じ周で同じ語を何度学習しても目標は進まない。1日の学習数には数える）。
    目標を作る前に学習記録のある語は1周目を済ませたものとして扱う。目標ごとに到達度テストの合格ライン（なし/70/80/90%）を設定可。
  ・フラッシュカード設定の出題元に「未学習のみ」を追加（学習記録のない語だけ）。
  ・期限はアプリ内カレンダーで任意の日を選択可（プリセットは選択中のボタンの色が変わる）。
  ・今日の振り返り：その日に学習した語（直近31日分を保存: store.log）を、フラッシュカードで復習／4択テスト。トップ・カレンダーから開く。
  ・テスト：ミニテスト（学習した語から）、到達度テスト（範囲全体からランダム。推定定着率を記録、推移グラフ）、振り返りテスト。クイズ（4択）の結果も反映。
    別の日に2回正解した語は「定着」（覚えたセットへ）。間違えた語は復習セットへ。（結果は store.tw、目標ごとのテスト履歴は goal.tests）
  ・単語マップ：各単語帳メニュー／目標から、語の状態（未学習・学習した・要復習・覚えた・定着）を色で一覧。
  ・sw.js の CACHE は v30。

【目標の編集・計画ラインの修正（2026-10 更新）】
  ・目標の名前は、空欄（自動）のままなら、範囲・周回数を編集すると名前も自動で付け直す（例：Unit 1〜2を3周／Unit 1 No.30〜60を2周）。自分で付けた名前は変わらない。
  ・数字の単位を「語（延べ語数）」に統一。進捗・計画との差・ノルマ・ペースはすべて語。
  ・計画ライン：目標を作った時点で済んでいた分（base）から、残りを「学習日」で均等に進める位置。ノルマの計算と同じ考え方。
    先行／遅れは今日の学習を始める前の時点で比較。範囲・周回数・期限・週の学習日数を編集すると、計画は今日から引き直す。
  ・旧バージョンで作った目標は、初回表示時に計画を今日から引き直す。sw.js の CACHE は v31。

【進捗の数え方・計画との差の修正（2026-10 更新）】
  ・「覚えた」（その方向）の語は、出題はしないが「今の周は済ませた」ものとして数える（以前は周回数ぶん数えていたため、周回数を変えると進捗の語数が増減した）。
    これにより、周回数を変えても進捗の語数は変わらず、％だけが変わる。
  ・「計画より◯語 先行／遅れ」は、進捗バーの黒い線（今日のノルマを終えた時点の計画位置）との差で表示。
    今日の分に届いていないだけのときは「今日の計画まで あと◯語」。
  ・計算方法の変更前に作った目標は、初回表示時に一度だけ計画を今日から引き直す（pv=2）。sw.js の CACHE は v32。

【意味の前に品詞・名詞の可算/不可算・方向別の記録・一覧の折りたたみ（2026-11 更新）】
  ・すべての意味の前に品詞を表示：【名C】【名U】【名C/U】【他】【自】【動】【形】【副】【熟】【接】【前】。意味の区切り（「、」）ごとに名詞のC/Uを判定
    （例：【名U】時間 【名C】時、〜回）。品詞バッジにも名詞のC/Uを表示。使われ方の補足は「可算・不可算」の行に表示。
  ・C/Uのデータは data/countable.js（CTB＝意味の区切りごとのラベル、CTN＝補足）。全冊（b1〜b7、名詞4,045語）を判定済み（C=2,502／U=1,085／C/U=458）。
    判定の確認・修正用に countability_all.csv を添付（修正後は作り直し）。sw.js の DATA に追加済み。
  ・学習記録を「英→日」「日→英」で別管理：学習済みの語（単語マップ・未学習のみ）、今日触れた語、振り返りの記録、目標。
    旧形式の記録・目標は英→日として引き継ぐ。触れた語の数は「語×方向」で数える。
    マッチング・神経衰弱は両方向、インベーダー・クイズ・テストは出題の方向、フラッシュカードは選んだ方向に記録。
  ・目標は方向を選んで作成（「両方向を同時に作る」で2つ作成）。作成後は方向を変更できない。目標の上限は6つ。自動の名前に方向が付く。
  ・覚えたセット／復習セットの一覧は、Unitごとに折りたたみ（初期は閉じる・「すべて開く／閉じる」あり）。
  ・クイズ・テストの選択肢は、品詞なしの意味（jm）を使用。sw.js の CACHE は v34（C/U判定を全冊に拡大）。

【目標の作り直し（2026-11 更新）】
  ・目標は「短期目標」「長期目標」の2つに固定（名称も固定）。範囲（単語帳・Unit/No）・周回数・期限（カレンダーで選択）を設定。
    週の学習日数は「詳細設定」（初期6日）。方向は区別せず、1語×2方向＝2問と数える（Unit 1の100語＝200問）。
  ・トップに「短期目標／長期目標」の切替と、％バー2本（本日の目標＝短期目標のノルマ、選択中の目標の進捗）を常に表示。連続日数・累計日数・最長連続は四角のボックスで表示。
    バーは計画どおり以上なら緑、遅れなら橙。黒い線は「今日のノルマを終えたときの計画位置」。円形グラフ・「今日の10語」・「目標の今日のノルマ」は廃止。
  ・「前回の続きから始める」：前回の方向で、前回最後に表示したカードの続きから範囲の最後まで普通に続ける（覚えたカードは飛ばす）。
    その方向を終えたら、次はもう一方の方向を範囲の最初から。方向はボタン下の「英→日／日→英」で切替可。
  ・カードをめくるか、めくらずに「覚えた」を押すと1問として数える（本日の目標にも加える）。短期と長期の範囲が重なるときは両方に数える。
  ・旧形式の目標（最大6つ・方向別）は、期限の近い順に短期・長期へ自動変換（同じ範囲の英→日・日→英は1つに統合）。合格ラインの設定は廃止。
  ・ミニテスト・到達度テスト・単語マップは目標画面のボタンから（方向は各画面で選択）。sw.js の CACHE は v35。
